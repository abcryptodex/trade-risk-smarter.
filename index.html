HELP & GUIDANCE

Support Center

Use this dashboard to plan, track and review trades.

How to use the tools

1. Decide how much capital you can afford to risk.

2. Set a stop-loss that matches your trade idea.

3. Check reward relative to risk, including costs.

4. Record the result and review what you learned.

Important limitations

Calculations are estimates. Fees, slippage, funding, liquidity, token taxes and exchange rules can change results.

The site does not place orders, connect wallets or sync to a database yet. This is an educational planning tool, not financial advice.
